# ELF Research

Research of different libraries for processing ELF files in terms of performance.

## Fetching dependencies

This project uses nix package manager as means to consume dependencies.

0) [Install nix package manager](https://nixos.org/download/)

1) Create development environment

```bash
nix develop
```

You may need to pass additional options to nix in case you do not have corresponding features set
in nix.conf.

```bash
nix develop --extra-experimental-features nix-command --extra-experimental-features flakes
```

There are 2 development environments:

- default
- elfio-pinned

Packages in the first one come straight from nixpkgs, while in the second one ELFIO library is taken
from
[a specific commit](https://github.com/serge1/ELFIO/commit/660e90514a2e80fba1c55f2cee07bbeda3d1c601).

Default environment can be entered using the command above. To enter *elfio-pinned* environment, use
the command below:

```bash
nix develop .#elfio-pinned
```

## Building

This project uses CMake as a build system. Consult your knowledge or the official documentation to
see how to run it.

## Benchmarking

Main objective of this project is to benchmark the time a bunch of libraries spent reading and
writing ELF files. The following libraries were studied:

- [ELFIO](https://github.com/serge1/ELFIO)
- [LIEF](https://github.com/lief-project/LIEF)
- [libelf](https://www.sourceware.org/elfutils)
- [LLVM](https://github.com/llvm/llvm-project/blob/main/llvm/include/llvm/Object/ELF.h)

To run benchmarking scripts you need to create a python virtual environment at first:

```bash
python3 -m venv .venv
```

Then install all dependencies and project modules:

```bash
.venv/bin/pip3 install scripts/benchmark
```

Actually running scripts is done in 2 stages. At first you run the script measuring the time spent
on generating ELF files:

```bash
.venv/bin/python3 .venv/bin/python3 scripts/benchmark/generator/run.py \
    --tmp-root tmp \
    --generator build/generator/generator \
    --libs=elfio,libelf \
    --sections-count=5000,10000,20000,30000 \
    --section-size=0x1000
```

Then you run the script measuring the time spent on reading ELF files. This script expects you to
run generation script at first because it searches for ELF files generated by ELFIO.

```bash
.venv/bin/python3 .venv/bin/python3 scripts/benchmark/loader/run.py \
    --tmp-root tmp \
    --loader build/loader/loader \
    --libs=elfio,lief,libelf,llvm
```

Presented commands are just examples, consult output of `--help` command for more information.
